# Components

- **`SwiftPMX`** (library) — reads a `.pmx` file (versions 2.0/2.1) and returns mesh geometry: vertex
  positions and the triangle index buffer. Handles left-handed → right-handed conversion, seam
  welding, degenerate-face culling, and uniform scale.
